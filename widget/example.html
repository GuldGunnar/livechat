Installation

Lägg till detta script på din webbsida:

<script src="https://livechat.nahe.se/widget/tracker.js"
        data-domain="din-domain.se"></script>

Hur det fungerar

  • Scriptet genererar en unik visitor_token som sparas i localStorage/cookie
  • När besökaren landar på sidan skickas ett enter event
  • Var 30:e sekund skickas en heartbeat för att hålla besöket aktivt
  • När besökaren lämnar skickas ett exit event
  • SPA-navigation (pushState) hanteras automatiskt
