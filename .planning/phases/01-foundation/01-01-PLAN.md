## Tasks

### Task 1: Create Database Schema
Create MySQL schema for visitor tracking.

**Files to create:**
- `sql/schema.sql` - Full database schema

**Schema requirements:**
```sql
CREATE DATABASE IF NOT EXISTS livechat;
USE livechat;

-- Projects table
CREATE TABLE projects (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    domain VARCHAR(255) NOT NULL,
    enabled TINYINT(1) DEFAULT 1,
    notification_browser TINYINT(1) DEFAULT 1,
    notification_ntfy TINYINT(1) DEFAULT 0,
    notification_sound TINYINT(1) DEFAULT 1,
    ntfy_topic VARCHAR(255) DEFAULT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_domain (domain),
    INDEX idx_enabled (enabled)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Visitors table
CREATE TABLE visitors (
    id INT AUTO_INCREMENT PRIMARY KEY,
    visitor_token VARCHAR(64) NOT NULL UNIQUE,
    ip_address VARCHAR(45) DEFAULT NULL,
    user_agent TEXT DEFAULT NULL,
    alias VARCHAR(255) DEFAULT NULL,
    first_seen TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_seen TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_visitor_token (visitor_token),
    INDEX idx_ip (ip_address)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Visits table (current page tracking)
CREATE TABLE visits (
    id INT AUTO_INCREMENT PRIMARY KEY,
    project_id INT NOT NULL,
    visitor_id INT NOT NULL,
    page_url VARCHAR(2048) NOT NULL,
    page_title VARCHAR(512) DEFAULT NULL,
    entered_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    exited_at TIMESTAMP DEFAULT NULL,
    is_active TINYINT(1) DEFAULT 1,
    FOREIGN KEY (project_id) REFERENCES projects(id) ON DELETE CASCADE,
    FOREIGN KEY (visitor_id) REFERENCES visitors(id) ON DELETE CASCADE,
    INDEX idx_project_active (project_id, is_active),
    INDEX idx_visitor_active (visitor_id, is_active),
    INDEX idx_entered (entered_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### Task 3: Create PHP Includes
Create shared PHP utilities following qrplan.eu patterns.

**Files to create:**
- `includes/db.php` - Database connection singleton
- `includes/response.php` - JSON response helpers
- `includes/cors.php` - CORS handling for tracking script

**db.php pattern:**
- Singleton PDO connection
- UTF-8mb4 charset
- Helper functions: dbQuery, dbQueryOne, dbExecute, dbLastInsertId
- Transaction support

**response.php pattern:**
- jsonResponse() with JSON_UNESCAPED_UNICODE
- jsonError() for error responses
- jsonSuccess() for success responses
- getJsonInput() for request body parsing
- requireMethod() for method validation

**cors.php pattern:**
- Allow any origin (tracking script runs on customer sites)
- Handle OPTIONS preflight
- Allow credentials for session tracking

### Task 4: Create API Router
Create the main API entry point.

**File to create:**
- `api/index.php` - Central API router

**Routes to scaffold:**
```
GET  /api/              - API info
POST /api/track         - Record visit (from widget)
GET  /api/visitors      - List active visitors (dashboard)
GET  /api/projects      - List projects (dashboard)
POST /api/projects      - Create project (dashboard)
```

**Pattern:**
- Parse URL into resource/id/action
- Route to appropriate handler files
- Exception handling with JSON error responses

### Task 5: Create Basic Track Endpoint
Create the tracking endpoint that the widget will call.

**File to create:**
- `api/track/index.php` - Handle tracking requests

**Functionality:**
- Accept POST with: project_domain, page_url, page_title, visitor_token
- Find or create visitor record
- Create/update visit record
- Return success response
